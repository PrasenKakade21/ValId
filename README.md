# ValID

Simple event management for events of all sizes.

ValID is an open-source event management platform built to fill the gap between platforms like BookMyShow and Devfolio, and managing a small event entirely through spreadsheets.

Big platforms offer a lot of powerful features, but smaller events often don't need all that complexity. ValID aims to provide the essentials for creating and managing organizations, events, attendees, and volunteers — without getting in the way.

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Supabase
- PostgreSQL
